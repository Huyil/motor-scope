## 匹配策略（优先级）

1. **DWARF struct 精确匹配**（437 条）：用 pyelftools 解析 `lks07x_Project.axf`，从顶层变量 DIE 沿变量路径逐段走 member，取叶子成员所在 struct/union 的类型名（匿名 struct 用链上 typedef 名，如 `STR_MotorFocSpeed`），再到源码解析出的 `struct 名 → 成员注释` 表精确取注释。共解析出 850 个变量的 struct 归属。
2. **叶子名唯一命中**（54 条）：叶子成员名在整个代码库的注释抽取中只有一种注释时直接使用。
3. **同名多义未解**（3 条）与 **无注释**（512 条）：不写 desc（禁止编造）。

工程中 struct 多为 `typedef struct {...} STR_Xxx,*PSTR_Xxx;` 匿名定义，取名从 `}` 后首个声明符提取。
